# Burp Suite Advanced — Request Interception and Intruder Fuzzing

## 1. Introduction to Burp Suite

Burp Suite is a web application security testing tool used by security professionals and penetration testers to identify vulnerabilities in web applications.

It works as an intermediary between a web browser and a web server. This allows testers to inspect, intercept, modify, and analyze HTTP requests and responses.

Burp Suite is commonly used for testing:

- Login and authentication mechanisms.
- Input validation.
- Session management.
- Web application parameters.
- Access control.
- Security vulnerabilities in HTTP requests.

### Main Features Used in This Practical

1. **Proxy:** Intercepts and inspects browser requests and server responses.
2. **Repeater:** Allows testers to manually modify and resend HTTP requests.
3. **Intruder:** Automates customized requests using different payloads.
4. **Target:** Displays the websites and resources being tested.
